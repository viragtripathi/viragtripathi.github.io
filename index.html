What happens in the walkthrough

I ask Codex to explore the demo database and its table schema, read the five newest synthetic samples, and explain the query plan. I then ask it to create a scratch table with generated UUID primary keys, insert two synthetic notes, and read them back. The recording shows the tool responses and resulting data.
